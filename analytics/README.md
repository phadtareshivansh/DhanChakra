# Analytics Notebooks

This directory contains Jupyter notebooks for prototyping structural analytics.

## Planned Notebooks

- `01_cycle_detection.ipynb` — NetworkX prototype for cycle detection
- `02_community_detection.ipynb` — WCC + Louvain/Leiden on sample data
- `03_centrality.ipynb` — PageRank, betweenness, degree centrality
- `04_entity_resolution.ipynb` — Deterministic + fuzzy matching
- `05_gnn_prototype.ipynb` — PyTorch Geometric GraphSAGE prototype

## Usage

```bash
cd analytics
jupyter lab
```
